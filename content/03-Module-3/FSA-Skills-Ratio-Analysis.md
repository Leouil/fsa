# FSA Skills: Ratio Analysis

> [!abstract] Skill Card
> A concise working reference for the ratio-analysis and synthesis techniques taught across the course. Use this when you need the core formulas, the interpretation questions they answer, and the red flags they expose — without re-reading the full learning objectives.

## The Ratio Family Tree

| Category | Ratio | Formula | Question Answered |
|---|---|---|---|
| **Profitability** | Gross margin | (Sales − COGS) ÷ Sales | What survives each revenue dollar before overhead? |
| | Operating margin | Operating income ÷ Sales | What survives each dollar excluding financing/tax? |
| | Net margin | Net income ÷ Sales | The all-in bottom line per sale |
| | ROA | Net income ÷ Total assets | How hard does the asset base work? |
| | ROE | Net income ÷ Stockholders' equity | The final return to owners |
| **Efficiency / Velocity** | DSO | Avg. AR ÷ (Sales ÷ 365) | Days to collect receivables |
| | DSI | Avg. inventory ÷ (COGS ÷ 365) | Days inventory sits before sale |
| | DPO | Avg. AP ÷ (COGS ÷ 365) | Days taken to pay suppliers |
| | Cash conversion cycle | DSI + DSO − DPO | Net days capital tied up |
| | Asset turnover | Sales ÷ Avg. total assets | Overall capital productivity |
| | Fixed-asset turnover | Sales ÷ Avg. net PP&E | Productivity of the fixed base |
| **Leverage** | Debt-to-assets | Total liabilities ÷ Total assets | Equity cushion / credit protection |
| | Financial leverage (equity multiplier) | Total assets ÷ Stockholders' equity | The ROA→ROE amplifier |

## Synthesis: The Du Pont Chain

```
ROA  = Asset Turnover × Net Margin
ROE  = ROA × Financial Leverage
FLI  = ROE ÷ Adjusted ROA        (Adjusted ROA adds back after-tax interest)
EPS  = Turnover × Margin × Leverage × Book value per share
g    = ROE × (1 − dividend payout)
```

Read the chain before the headline number: *which lever moved?* ROE can rise on added debt risk while operations decay — FLI tells you whether debt actually earns above its after-tax cost.

## Analyst Disciplines That Protect Every Ratio

- **Common-size first, then dollars** — normalize structure, then zoom back into absolute materiality
- **Average the balance sheet** — pair full-year income with average (not year-end) stocks
- **Strip one-offs before trending** — one exceptional base year contaminates every index and CAGR built on it
- **Read direction, not just level** — a single year says little; three years tell a story
- **Decompose before judging** — never praise (or bury) a ratio without seeing its components
